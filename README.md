# Bili Mitsubishi

Website sales consultant Mitsubishi Motors & FUSO, Bosowa Berlian Motor Kairagi, Manado.

**Website:** https://gsuban098-dev.github.io/bili-mitsubishi/

## Mengubah isi website

| Yang diubah | File |
| --- | --- |
| Nama sales, nomor WhatsApp, alamat, jam operasional, lokasi peta | `assets/js/config.js` |
| Harga, spesifikasi, dan varian kendaraan | `assets/js/main.js` (array `MODELS`) |
| Teks halaman, judul, dan meta SEO | `index.html` |
| Warna dan tampilan | `assets/css/style.css` |

Setiap perubahan yang di-push ke branch `main` otomatis tayang di GitHub Pages dalam 1–2 menit.

## Catatan

- Harga yang tercantum adalah estimasi. Perbarui sesuai pricelist resmi terbaru.
- Situs ini dikelola pribadi oleh sales consultant dan bukan situs resmi Mitsubishi Motors maupun FUSO.
